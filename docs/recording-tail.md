# Enter停止時の語尾保持

## 現在の動作: 追加待機なし

操作の速さを優先するユーザー要望により、Enter後の録音延長は無効。
Enter押下直後に録音を止め、文字起こしへ進む。認識・通信と貼り付け後の送信待ちは残る。
Enter後の発話は収録されないため、話し終えてから押す。
`RecordingStopPresentationTests`で追加待機が0秒であることを検証する。

## 以前の方式（現在は使わない）

Enter後は音量を25ms間隔で確認し、最後に声を検出してから0.35秒待って録音を終了する。
停止要求後の延長は最大1.5秒。環境音が続いても録音し続けない。
声の判定は既存の正規化音量で0.25以上（音声認識による判定ではない）。
Fn・メニュー停止、会話モードのキャンセル動作は変更しない。

回帰テスト: `RecordingTailPolicyTests`。固定0.35秒停止へ戻すと、継続発話・短い間・小声のケースで失敗する。
実発話では語尾とEnter押下を重ね、語尾が残るか確認する。小声や騒音下では追加調整が必要な可能性がある。
文字起こしエンジン自体の認識漏れや、最大延長を超える発話はこの対策の保証範囲外。
